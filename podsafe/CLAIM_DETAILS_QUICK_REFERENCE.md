```
        ↓

        ↓

        ↓

        ↓

7. NOTES (Highlighted section)
```

**Result**: Information scans naturally

---

## 💡 Design Patterns

### Pattern 1: Color Coding
- Green = Approved ✓
- Red = Rejected ✗
- Orange = Pending ⏱️
- Blue = Processing ⚙️
- Purple = Investigating 🔍

### Pattern 2: Size Hierarchy
- Large circles = Important (milestones)
- Medium text = Primary info
- Small text = Secondary info

### Pattern 3: Spacing
- 16px padding inside cards
- 24px between sections
- 12px between elements
