## How It Works

### Step 1: Create Claim
Admin creates a claim without photos/signature:
```dart
final claimId = await provider.createClaimWithoutEvidence(claim);
// Claim saved to Firestore with evidenceStatus = 'pending'
```

### Step 2: Later - Upload Evidence
When evidence becomes available, upload it:
```dart
await provider.uploadEvidenceToClaim(
  claimId: claimId,
  photos: [photo1, photo2],
  signature: signatureFile,
);
// Claim updated with evidence, evidenceStatus = 'received'
```

### Step 3: Track Progress
Dashboard shows pending evidence claims:
```dart
final pendingClaims = await provider.getClaimsPendingEvidenceCount();
// Shows "3 claims pending evidence"
```

## Usage Examples

### Example 1: Admin Creates Claim
```dart
const claim = Claim(
  title: 'Damaged Goods',
  description: 'Box arrived damaged',
  // ... other required fields ...
  evidenceStatus: 'pending', // Auto-set
);

final claimId = await provider.createClaimWithoutEvidence(claim);
// Claim is now in system, waiting for evidence
```

### Example 2: Driver/Admin Uploads Evidence
```dart
final photoFile = await FilePicker.platform.pickFiles();
final signatureFile = await getSignature();

await provider.uploadEvidenceToClaim(
  claimId: claimId,
  photos: [File(photoFile.path)],
  signature: signatureFile,
);
// Evidence uploaded, status automatically updated
```

### Example 3: Dashboard Shows Pending Claims
```dart
StreamBuilder<List<Claim>>(
  stream: provider.getClaimsPendingEvidenceStream(),
  builder: (context, snapshot) {
    return ListView(
      children: snapshot.data
          ?.map((claim) => PendingClaimTile(claim: claim))
          .toList() ?? [],
    );
  },
)
// Shows all claims waiting for evidence
```
