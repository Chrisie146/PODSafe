# Claims PDF Export - Quick Reference

## 🎯 What's New

Claims can now be exported as **professional PDF reports** or **CSV files** - just like PODs!

---

## 📥 How to Use

### Step 1: Open Claims Management
- Navigate to **Claims Management Desktop**
- See your claims in the table

### Step 2: (Optional) Select Claims
- Click the **checkbox icon** to enable multi-select
- Click "Select All" or select individual claims
- Or skip this to export all visible claims

### Step 3: Click Export
- Click the **download button** (⬇️) in the top right
- Choose export format:
  - **PDF Reports** - Professional formatted documents
  - **CSV** - Spreadsheet for analysis

### Step 4: Download
- Progress dialog shows export is processing
- File downloads automatically when complete
- Success message confirms export

---

## 📊 Export Options

### PDF Export
✅ **Perfect for:**
- Professional reports for stakeholders
- Archiving claim documentation
- Email sending (professional appearance)
- Printing claim records

📦 **What you get:**
- ZIP file with one PDF per claim
- Complete claim information
- Driver and customer details
- Timestamps and status

### CSV Export
✅ **Perfect for:**
- Data analysis in Excel/Sheets
- Reporting and dashboards
- Bulk data processing
- Accounting reconciliation

📊 **What you get:**
- Single CSV file with all claims
- All relevant columns
- Easy filtering/sorting
- Import to other systems

## 🎯 Quick Tips

### Tip 1: Export Filtered Results
1. Filter by **Status** (e.g., "Approved")
2. Filter by **Date Range** (e.g., "Last 30 days")
3. Click Export → Choose format
4. Only filtered claims export ✓

### Tip 2: Export Selected Claims
1. Enable **multi-select** (checkbox icon)
2. Click **"Select All"** or choose individually
3. Click Export
4. Only selected claims export ✓

### Tip 3: Export for Analysis
1. Apply your filters (status, date, etc.)
2. Choose **CSV export**
3. Open in Excel/Google Sheets
4. Create pivot tables, charts, etc.

### Tip 4: Professional Reports
1. Filter to specific claims
2. Choose **PDF export**
3. Get professional-looking documents
4. Send via email or print

## 📋 PDF Report Contents

Each PDF includes:
- **Claim ID & Timestamp**
- **Claim Details** (type, status, amount)
- **Customer Info** (name, phone, address)
- **Driver Info** (name, phone, license)
- **Order Details** (order #, invoice, date)
- **Description** (full claim description)
- **Timeline** (created & updated dates)
- **Resolution Notes** (if available)

## ⚠️ Troubleshooting

**Q: Export button not working?**
A: Try refreshing the page, check your permissions, or try again.

**Q: Can't find the export button?**
A: Look for the download icon (⬇️) in the header next to Refresh.

**Q: PDF file is incomplete?**
A: This is rare - make sure all claim data is filled in. Try a single claim first.

**Q: CSV won't open in Excel?**
A: Try opening as UTF-8 or use "Get & Transform Data" in Excel.

**Q: ZIP file is too large?**
A: Export fewer claims at once or use CSV format instead.
