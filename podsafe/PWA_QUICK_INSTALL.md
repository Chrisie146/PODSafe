# PODSafe Admin - PWA Quick Install Guide

## ⚡ One-Minute Installation

### Windows (Chrome/Edge)
1. Go to: https://podsafe-92a3e.web.app
2. Click **⬇️** icon in address bar (or **+** in Edge)
3. Click **Install**
4. Done! ✅ App appears in your applications

### Mac (Chrome)
1. Go to: https://podsafe-92a3e.web.app
2. Click **⬇️** icon in address bar
3. Click **Install**
4. Done! ✅ App appears in Launchpad

### iPad/Tablet (Safari)
1. Go to: https://podsafe-92a3e.web.app
2. Tap **Share** (bottom center)
3. Select **"Add to Home Screen"**
4. Done! ✅ Icon on home screen

---

## 🎯 What Happens After Installing?

✅ App appears in your **applications/Launchpad**  
✅ No address bar when you launch it  
✅ Looks and feels like a native app  
✅ Easy access from taskbar/dock  
✅ Professional PODSafe branding

## 📌 Launch After Installing

**Windows:**
- Click Start Menu
- Search "PODSafe"
- Click the app

**Mac:**
- Open Launchpad
- Find "PODSafe"
- Click to launch

**iPad:**
- Swipe to home screen
- Tap the PODSafe icon

---

## 🔧 Don't See the Install Button?

1. **Clear Browser Cache**
   - Chrome: `Ctrl+Shift+Delete`
   - Mac: `Cmd+Shift+Delete`

2. **Close & Reopen Browser**

3. **Go to:** https://podsafe-92a3e.web.app

4. **Wait 3-5 seconds** for the **⬇️** icon to appear

---

## 💡 Tips

- **Pin to Taskbar** (Windows): Right-click app → "Pin to taskbar"
- **Dock (Mac)**: Right-click app → "Options" → "Keep in Dock"
- **Full Screen**: App launches full-screen (no address bar)
- **Keyboard**: Use `Ctrl+Q` or `Cmd+Q` to quit
