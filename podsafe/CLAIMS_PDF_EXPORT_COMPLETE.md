# Claims PDF Export Feature - Complete Documentation

## 🎯 Overview

Added professional PDF export functionality for claims, mirroring the POD download feature. Claims can now be exported as:
1. **PDF Reports** - Professional formatted PDF documents with complete claim details
2. **CSV Files** - Spreadsheet format for data analysis

---

## ✨ Features

### 1. PDF Export
- **One-Click Export**: Click download button → Select "Export as PDF Reports"
- **Multiple Formats**: Each claim generates a professional PDF
- **ZIP Packaging**: All PDFs bundled into a single ZIP file
- **Complete Details**: Includes claim info, customer data, driver info, order details, and resolution notes

### 2. CSV Export
- **Spreadsheet Format**: Easy for analysis and further processing
- **All Claim Data**: Exports all visible/selected claims as CSV
- **Filtered Export**: Respects current filters (status, type, date range)
- **Bulk Processing**: Export multiple claims at once

### 3. Multi-Select Integration
- **Smart Selection**: Export selected claims if multi-select is active
- **Filtered Export**: Export all visible claims if no selection
- **Company Isolation**: Only exports current company's claims (security)

## 🔧 Implementation Details

### BulkClaimsPdfService Class

#### Main Methods

**`downloadClaimsAsZip()`**
```dart
static Future<void> downloadClaimsAsZip({
  required List<String> claimIds,
  required String companyId,
  required Function(double) onProgress,
})
```
- Downloads multiple claims as individual PDFs in ZIP format
- Accepts progress callback (0.0 to 1.0)
- Verifies company ID for security
- Shows loading during export

**`exportClaimsAsCSV()`**
```dart
static Future<void> exportClaimsAsCSV({
  required List<String> claimIds,
  required String companyId,
  required Function(double) onProgress,
})
```
- Exports claims to CSV spreadsheet
- Includes headers and all relevant claim data
- Company ID verification

**`_generateClaimPDF()`**
```dart
static Future<Uint8List?> _generateClaimPDF({
  required String claimId,
  required Map<String, dynamic> claimData,
})
```
- Generates single claim PDF with complete details
- Fetches related delivery and driver information
- Handles null/missing data gracefully

#### Helper Methods

**`_buildClaimSection()`** - Formats PDF sections
**`_buildInfoRow()`** - Formats key-value pairs in PDF

## 📊 PDF Content Structure

Each exported claim PDF includes:

1. **Header**
   - Title: "CLAIM REPORT"
   - Subtitle: "Official Claim Documentation"

2. **Identifiers**
   - Claim ID
   - Generated timestamp

3. **Claim Information**
   - Invoice Number
   - Claim Type (Damage, Shortage, Missing, etc.)
   - Status (Submitted, Pending, Approved, Rejected)
   - Claim Amount (in ZAR)

4. **Customer Information**
   - Customer Name
   - Customer Number
   - Customer Address
   - Customer Phone

5. **Driver Information**
   - Driver Name (with fallback to fullName)
   - Driver Phone Number
   - License Number

6. **Order Details**
   - Order Number
   - Invoice Total (with currency)
   - Delivery Date

7. **Claim Description**
   - Full claim description text

8. **Timeline**
   - Created Date/Time
   - Last Updated Date/Time

9. **Resolution Notes** (if available)
   - Full resolution notes text

10. **Footer**
    - "Official claim report generated by PodSafe"

## 🔐 Security Features

1. **Company ID Verification**
   - Each claim checked against company ID
   - Claims from other companies excluded
   - Prevents data leakage between companies

2. **User Authentication**
   - Uses AuthProvider for company verification
   - Only authenticated users can export
   - Logging available via debugPrint

3. **Data Isolation**
   - Respects multi-select and filters
   - Only exports visible/selected claims
   - No unauthorized data access

---

## 📱 Integration with Multi-Select

### Behavior
1. **With Multi-Select Active & Items Selected**
   - Exports only selected claims

2. **With Multi-Select Active & No Selection**
   - Exports all filtered/visible claims

3. **With Multi-Select Inactive**
   - Exports all filtered/visible claims
   - Can enable multi-select to choose specific claims

---

## 🔄 Filtering Support

The export respects all active filters:
- **Status Filter** - Only exports selected status
- **Type Filter** - Only exports selected claim type
- **Date Range** - Only exports claims within date range
- **Search Query** - Only exports matching claims

## 🚀 Usage Examples

### Example 1: Export Single Claim
1. Click the download icon
2. Select "Export as PDF Reports"
3. If only 1 claim selected, generates 1 PDF in ZIP
4. Download starts automatically

### Example 2: Bulk Export All Pending
1. Filter by Status: "Pending"
2. (Optional) Enable multi-select and click "Select All"
3. Click download → "Export as PDF Reports"
4. All pending claims exported as PDFs in ZIP

### Example 3: Export for Analysis
1. Filter by date range (e.g., last 30 days)
2. Click download → "Export as CSV"
3. Import into Excel/Google Sheets for analysis
4. Create pivot tables, charts, etc.

## 📞 Support & Troubleshooting

### Export button doesn't work
- Verify you're logged in
- Check company permissions
- Refresh page if needed

### PDF looks incomplete
- Check that delivery/driver data exists
- Verify Firestore permissions
- Try exporting a single claim first

### File download doesn't start
- Check browser download settings
- Verify pop-ups aren't blocked
- Try different browser

### CSV export has encoding issues
- Use UTF-8 when opening in Excel
- Try importing with specific delimiter
