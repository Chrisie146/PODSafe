# PODSafe Logo Placeholder

This is a placeholder file. Please replace this with your actual logo image.

## Image Requirements:

### For App Icon (logo.png):
- **Dimensions**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Design**: 
  - Simple, recognizable logo
  - Use PODSafe brand color: #0A7E8C (teal)
  - Leave padding around edges
  - Avoid small text

### For Splash Screen (splash_logo.png):
- **Dimensions**: 512x512 pixels or larger
- **Format**: PNG with transparency
- **Design**:
  - Centered logo on transparent background
  - Will be displayed on teal background (#0A7E8C)
  - Can be the same as logo.png

## Quick Design Options:

1. **Use a free logo maker**:
   - Canva: https://www.canva.com
   - LogoMakr: https://logomakr.com
   - Hatchful: https://hatchful.shopify.com

2. **Design concepts**:
   - Delivery truck icon
   - Package with checkmark
   - Shield + truck (security + delivery)
   - "PS" monogram

3. **Color scheme**:
   - Primary: #0A7E8C (teal)
   - Accent: #FFFFFF (white)

## Installation:

1. Create your logo images
2. Save as `logo.png` (1024x1024px) in this folder
3. Save as `splash_logo.png` (512x512px or larger) in this folder
4. Run: `flutter pub get`
5. Run: `flutter pub run flutter_launcher_icons`
6. Run: `flutter pub run flutter_native_splash:create`
7. Rebuild your app

For detailed instructions, see SPLASH_AND_ICON_SETUP.md
