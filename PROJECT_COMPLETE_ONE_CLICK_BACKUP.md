## 🎓 How It Works (Overview)

```
User clicks "Backup All Data"
        ↓
Progress dialog appears
        ↓
Service queries all collections
├─ Deliveries (with photos)
├─ Drivers
├─ Claims (with evidence)
└─ PODs (with photos)
        ↓
Service downloads all images
        ↓
Service creates organized ZIP
├─ README.txt
├─ Metadata
├─ Deliveries folder + images
├─ Drivers folder
├─ Claims folder + evidence
└─ PODs folder + images
        ↓
Browser triggers download
        ↓
Firestore updates with backup date
        ↓
Success notification shown
        ↓
ZIP available in Downloads folder
```
