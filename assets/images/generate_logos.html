🚚 PODSafe Logo Generator

Instructions:

  1. Click the "Download" buttons below each image
  2. Save as logo.png and splash_logo.png
  3. Place both files in assets/images/ folder
  4. Run: flutter pub get
  5. Run: flutter pub run flutter_launcher_icons
  6. Run: flutter pub run flutter_native_splash:create
